# 끝말잇기 낱말 사전

초등학생이 끝말잇기를 하면서 **많은 낱말과 뜻을 배우도록** 만든 검색 사이트입니다.
글자 하나를 넣으면 그 글자로 시작하는 낱말과 쉬운 뜻을 보여 줍니다.

- 글자로 시작하는 낱말을 가나다순으로 보여 주고, 난이도를 쉬움·중간·어려움으로 표시합니다.
- 두음법칙을 적용해 함께 찾아 줍니다. (예: '력' → '역')
- 낱말마다 끝 글자로 이을 수 있는 낱말 수를 보여 주고, 누르면 바로 이어서 찾습니다.
- 이을 낱말이 없으면 '한방 단어'로 알려 줍니다.

## 난이도 기준

국립국어원 「국어 기초 어휘 선정 및 어휘 등급화 목록」의 등급을 따릅니다.

| 표시 | 등급 |
|---|---|
| 쉬움 | 1~2등급 (학령 전 ~ 초등 1~2학년) |
| 중간 | 3등급 (초등 3~4학년) |
| 어려움 | 4등급 |

두 글자 이상인 명사만 담았습니다.

## 데이터 출처

- 낱말과 등급: 국립국어원 「국어 기초 어휘 선정 및 어휘 등급화 목록」(2023), 공공누리 제1유형
- 뜻풀이: 국립국어원 [한국어기초사전](https://krdict.korean.go.kr), 기초사전에 없는 낱말은 [표준국어대사전](https://stdict.korean.go.kr) 뜻풀이의 첫 뜻 (CC BY-SA 2.0 KR)

`words.json`의 뜻풀이는 위 사전의 라이선스(CC BY-SA 2.0 KR)를 따릅니다.

## 데이터 다시 만들기

1. [한국어기초사전 오픈 API](https://krdict.korean.go.kr/kor/openApi/openApiInfo) 키를 받아 프로젝트 폴더에 `.env` 파일을 만듭니다.
   ```
   KRDICT_API_KEY=발급받은키
   ```
2. 실행합니다. (`openpyxl` 필요)
   ```
   python scripts/build_words.py
   ```
   중간에 멈춰도 다시 실행하면 이어서 진행합니다.
